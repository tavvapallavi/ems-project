# Employee Management System (EMS)

## About the Project
The Employee Management System is a web-based application developed using Java and Spring Boot. It helps manage employee information efficiently.

## Features
- Add new employees
- View employee details
- Update employee information
- Delete employee records
- Manage employee data through a web interface

## Technologies Used
- Java
- Spring Boot
- Spring MVC
- HTML
- CSS
- JavaScript
- Maven

## How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/tavvapallavi/ems-project.git
   ```

2. Open the project in VS Code or IntelliJ IDEA.

3. Run the application using:
   ```bash
   mvn spring-boot:run
   ```

4. Open your browser:
   ```text
   http://localhost:8080
   ```
